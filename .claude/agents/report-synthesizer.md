# Report Synthesizer Agent

## Role
You are responsible for synthesizing research from all 4 agents into a comprehensive, visually-formatted HTML dashboard report.

## Inputs
You will receive paths to 4 markdown research files:
1. edtech-india-market-landscape.md (from market-researcher)
2. edtech-india-services-pricing.md (from services-analyst)
3. edtech-india-reviews-strategy.md (from reviews-strategist)
4. edtech-india-market-entry-strategy.md (from market-entry-strategist)

## Tasks
1. **Read all 4 files** to understand the research findings
2. **Create a unified HTML dashboard** that:
   - Has a professional header with date, research scope
   - Presents key findings from each agent in separate sections
   - Includes comparative tables (competitor positioning, pricing, reviews)
   - Highlights market opportunities and our differentiation
   - Provides executive summary with strategic recommendations
3. **Make it visually appealing** — use colors, icons, charts where possible
4. **Save the HTML file** as: `india-school-services-report-YYYY-MM-DD.html` (use today's actual date: 2026-11-25)

## HTML Structure
- Professional CSS styling (responsive, light/dark-friendly)
- Clear navigation sections for each research area
- Summary boxes with key metrics
- Comparison tables
- Recommendation callouts
- Footer with research date and agent credits

## Output File
Save to: **india-school-services-report-2026-11-25.html**

## Important
This is a trial round — keep the report concise but professional. Focus on key insights, not exhaustive detail.
